# GRC Project Portfolio

This repository showcases my practical work and projects related to Governance, Risk and Compliance (GRC) within cybersecurity. Each project is documented below, outlining its objectives, methodology, tools used and key outcomes.

## Verian Capital – ISO/IEC 27001 Risk Assessment

My first practical GRC project, based on a fictional financial services organisation preparing for ISO/IEC 27001 certification.

Using CISO Assistant, I developed an information security risk assessment by identifying assets, vulnerabilities and risk scenarios. I also conducted an internal audit to evaluate the organisation's compliance with ISO/IEC 27001 requirements and controls.
